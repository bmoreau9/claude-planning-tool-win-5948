## About Claude Planning Tool

Claude Planning Tool helps developers and other technical users prepare structured prompts for Claude Code. Instead of composing every planning detail manually, users select a Claude model, describe the application focus, and choose an effort level before producing a prompt that is ready to copy into their workflow.

The tool is designed as a lightweight browser-based planning utility with an offline planning engine. Its focused interface supports repeatable prompt preparation for development, productivity, and automation tasks without requiring a separate command-line setup.

- Select from available Claude models.

1. Launch Claude Planning Tool in your browser.
2. Select the Claude model you want to use.

## FAQ

### Who is Claude Planning Tool for?

It is intended for users who work with Claude Code and want a more structured way to prepare project prompts.

### Does it support different Claude models?

Yes. The tool includes model selection as part of the prompt planning workflow.

### Can I use it without an internet connection?

The planning engine supports offline use. Internet access may still be needed for the hosted version and automatic update checks.

### Where are settings configured?

Model, application focus, and effort choices are set directly in the tool's interface.

### How do I copy a generated prompt?

Generate the prompt, then use the tool's clipboard action to copy it for use in Claude Code or another workflow.

### What should I do if the tool does not open?

Confirm that you are using a current browser on Windows. For a local copy, verify that the repository was downloaded completely and that the main HTML file is opened in the browser.

### How are updates handled?

The tool includes automatic update checks. You can also revisit the published build to obtain the latest available version.
